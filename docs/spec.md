# 仕様メモ

浮世勤怠帖の決まりごとをまとめたものです。`index.html` を変えるときの手がかりにしてください。
以下の時刻の例は、設定の既定（始業 10:00・終業 19:00・休憩 1:00）のときのものです。

## 1. 保存

- 記録と設定は `localStorage` の `ukiyo-kintai:v1` に JSON で保存する。サーバーには送らない。
- 1日分の記録（キーは `YYYY-MM-DD`）：

| 項目 | 内容 |
| --- | --- |
| `kind` | `normal`（通常勤務）／`late`（遅刻）／`early`（早退）／`absent`（欠勤）／`leave`（有休）／`holidaywork`（休日出勤）／`none`（記録なしにした日） |
| `start` `end` `brk` | 開始・終了・休憩（`HH:MM`、休憩は `H:MM`） |
| `punchIn` `punchOut` | 実際にボタンを押した時刻 |
| `task` | 作業内容（作業場所） |
| `note` | 開始の理由（遅刻など）／欠勤・有休の理由 |
| `endNote` | 早く終えた理由 |
| `part` | 有休の区分（終日／午前休／午後休） |
| `teams` | Teams に毎日の投稿をした時刻 |
| `sent` | 連絡を送った記録（`own` 自社／`site` 現場先／`teams`） |

## 2. 打刻

- **出勤する**：通常の日は始業時刻（10:00）で記録し、変えられない。遅刻・休日出勤のときだけ15分刻みで選べる。打刻した実時刻は `punchIn` に残す。
- **退勤する**：15分刻みのプルダウンで終了時刻を選ぶ（既定は終業 19:00）。
- **押し忘れ**：設定の「使い始めた日」以降の過去の平日で記録がない日は、通常勤務（10:00〜19:00）として扱う。出勤だけ押して退勤がない日は、終了を 19:00 として扱う。
- **平日**：土日と日本の祝日（振替休日・国民の休日を含む）以外。土日祝に出勤すると「休日出勤」。

## 3. 勤務時間と残業

- 時間 ＝ 終了 − 開始 − 休憩
- 所定 ＝ 終業 − 始業 − 休憩（既定では 8:00）
- 残業 ＝ 時間 − 所定（0未満は0）
- まとめの数字は「今日より前の日」（確定分）だけで計算する。
- 残業注意：今月の残業が上限の6割以上、または月末の見込みが上限をこえるとき、ホームに知らせを出す。見込み ＝ 残業 ＋（残業 ÷ 出勤日数）× 残りの平日数。

## 4. Teams への投稿（1日1回、退勤のとき）

退勤の画面で文面を確かめてから「Teams に投稿する」を押したときだけ送る。

| その日 | 文面 |
| --- | --- |
| 10:00 出勤・19:00 以降に退勤（残業も含む） | `10/27 19:00 業務終了` |
| 開始が 10:00 以外 | `10/30 10:15 業務開始` ／ `電車遅延のため` ／ `10/30 19:00 業務終了` |
| 19:00 より前に退勤 | `10/30 15:00 業務終了` ／ `通院のため` |
| 欠勤・有休（連絡のメール画面から投稿） | `11/20 欠勤` ／ `体調不良（発熱）のため` |

- 残業（19:00 より後の退勤）には理由の行を入れない。
- 先の日付の有休は、登録したときに投稿できる（連絡のメール画面の「Teams」タブ）。
- 送り方：ワークフローの webhook URL に Adaptive Card（1行ずつの TextBlock）を POST する。ブラウザの制限で中身を確かめられない場合は `no-cors` で送り、届いたかの確認を利用者に促す。

## 5. 連絡のメール（自社宛て・現場先宛て）

1通ずつ、押したときだけメールアプリを開いて送る（`mailto:`）。送る前に件名と本文を直せる。

### 自社宛て

件名：`【勤怠連絡】{姓}　{M/D}{種類}`（種類：遅刻／早退／欠勤／休暇取得）

```
各位

お疲れ様です。
{部署}　{姓}です。

当日連絡で申し訳ありません。        ← 連絡する日がその日のときだけ
下記日程で{遅刻／早退／欠勤／有給休暇を取得}致します。
{M/D（曜）}　{11:30出社予定／15:00退社予定／午前休}　理由：{理由}

※現場調整済みです。

どうぞよろしくお願い致します。
```

### 現場先宛て

件名：`{現場での所属}　{氏名}`

```
各位

お疲れ様です。
{現場での所属}の {姓}です。

{本文}
```

| 種類 | 本文 |
| --- | --- |
| 遅刻 | `{理由}遅れます。`（空行）`{11時30分}までには出社できる見込みです。` |
| 早退 | `{理由}、本日は{15時}に早退します。` |
| 欠勤 | `{理由}、本日はお休みをいただきます。` |
| 有休 | `{M/D（曜）}は、{理由}休暇をいただきます。` |

時刻の書き方：11:30 →「11時30分」、11:00 →「11時」。

## 6. 月末の書き出し

会社の Excel と同じ列で、その月の1日から末日まで1行ずつ出す。

`月日 / 勤怠区分 / 開始 / 終了 / 休憩 / 時間 / 作業内容（作業場所） / 備考`

- 月日は `11/2(月)` の形。
- 勤怠区分は 通常勤務／遅刻／早退／欠勤／有休／休日出勤。
- 欠勤・有休は時刻の列を空欄にする。土日祝と記録のない日は月日だけ。
- 「Excel用に写す」はタブ区切り（Excel に貼るとセルに分かれる）。同じ内容を JSON でも写せる。

## 7. デザイン

デザインシステム「浮世勤怠帖」に従う。

- 色：和紙 `#F2EAD8`・生成 `#FAF5EA`・墨 `#2A2520`・朱 `#A83A28`。状態色は 出 藍／退 墨／遅 山吹／早 薄墨／欠 朱／休 若草。色だけに頼らず、漢字一文字の印を添える。
- 書体：Yuji Syuku（あいさつ1行）・Shippori Mincho B1（見出し・数字）・Zen Kaku Gothic New（本文）。
- 画面名は右上の朱の縦書き短冊。完了の印は朱の角印（落款）。
- 挿絵は1画面に1枚まで（群像も1枚と数える）。役：扇の蛙＝ホーム、鼠の行列＝出勤、猫の行列＝退勤、走る白鼠＝遅刻・早退、跳ねる蛙＝有休、文を書く女＝連絡のメール、踊る蛙たち＝登録完了、采配の蛙＝まとめ、がしゃどくろ＝欠勤・残業注意（暗い面）。
