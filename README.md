# 浮世絵勤怠帖（うきよきんたいちょう）

和紙に墨、朱をひと差し。浮世絵の佇まいでつくった、**個人用の勤怠アプリ**です。

- 出勤・退勤をスマホで打刻（押し忘れても既定の時刻で入ります）
- 遅刻・早退・欠勤・有休を登録し、**自社宛て・現場先宛てのメール**をそのまま作成
- 毎日の退勤時に、**Teams の毎月のスレッドへ1日1回の返信**（文面を確かめてから送信）
- 暦（カレンダー）で過去の日を修正
- 月のまとめ（出勤日数・合計勤務・残業）と残業の注意
- 月末に **会社の Excel と同じ列**で書き出し（貼り付けるだけ）

**アプリの URL：<https://i4fue7b5ux-coder.github.io/ukiyo-kintai/>**

記録と設定は、**使う人のスマホの中（ブラウザ）にだけ**保存されます。同じ URL を何人で使っても、記録が混ざったり、ほかの人に見えたりすることはありません。

## 1. スマホに入れる

1. いつものブラウザで <https://i4fue7b5ux-coder.github.io/ukiyo-kintai/> を開きます
   - iPhone は **Safari**、Android は **Chrome**
   - **プライベートブラウズ（シークレットモード）では開かないでください。** タブを閉じると記録が消えます
   - Teams・LINE・メールなどのアプリの中でリンクを開くと、記録が残らないことがあります。URL をコピーしてブラウザに貼って開いてください
2. ホーム画面に追加します
   - iPhone（Safari）：下の共有ボタン（□に↑）→「**ホーム画面に追加**」
   - Android（Chrome）：右上の「︙」→「**ホーム画面に追加**」または「**アプリをインストール**」
3. **これからは、ホーム画面のアイコンから開いてください。**
   ブラウザのタブで開いたときと、ホーム画面のアイコンから開いたときでは、記録の保存場所が別になることがあります。

> ホーム画面のアイコンを削除すると、そのアプリの記録も一緒に消えます。消す前に [バックアップ](#7-記録のバックアップ) を取ってください。

## 2. 設定を入れる

ホーム（またはまとめ）の右上、朱の短冊の左にある**歯車**を押すと設定が開きます。
入力欄から離れると自動で保存されます（画面の下に「保存しました」と出ます）。

### あなたのこと

| 項目 | 入れるもの | 使われるところ |
| --- | --- | --- |
| 姓 | 例：山田 | メールの件名・本文（「第一ソリューション部　山田です」など） |
| 氏名 | 例：山田花子 | 現場先宛てメールの件名（「データ支援　山田花子」） |
| 自社での部署 | 例：第一ソリューション部 | 自社宛てメールの本文 |
| 現場での所属 | 例：データ支援 | 現場先宛てメールの件名と本文 |

### 連絡先

| 項目 | 入れるもの | 使われるところ |
| --- | --- | --- |
| 自社宛てのメール | 自社の勤怠連絡の宛先 | 「自社に送る」 |
| 現場先宛てのメール | 現場先の連絡の宛先 | 「現場に送る」 |
| 自分のメール | 自分のアドレス（入れなくても可） | 月末の「自分にメールで送る」 |
| Teams のワークフロー URL | [3. Teams に投稿できるようにする](#3-teams-に投稿できるようにする) で作った URL | 毎日の投稿、欠勤・有休の投稿 |
| 返信先スレッドのリンク（毎月） | 今月のスレッドのリンク | Teams の返信先 |

「**テストを1通送る**」で、Teams のスレッドに届くか確かめられます。

### いつもの勤務

| 項目 | 既定 | 使われるところ |
| --- | --- | --- |
| 始業・終業・休憩 | 10:00・19:00・1:00 | 押し忘れたときの時刻、残業の計算 |
| 作業内容（作業場所）の初期値 | 空欄 | 月末の書き出しの「作業内容」列（例：データ分析（初台）） |
| 残業の上限（時間／月） | 20 | 残業注意の画面 |
| 使い始めた日 | 初めて開いた日 | この日より前で記録のない日は、書き出しで空欄になります |

- 所定の勤務時間は「終業 − 始業 − 休憩」（既定では 8 時間）で、これをこえた分が残業になります。
- 押し忘れた日は、始業〜終業の通常勤務として扱います。違っていたら [暦](#暦で直す) で直せます。

### 記録のバックアップ

[7. 記録のバックアップ](#7-記録のバックアップ) を見てください。「見本の記録を入れて試す」を押すと、今月の過去の日に見本の記録が入り、暦やまとめの見え方を試せます。試したあとは暦で直すか、「すべて消す」で消せます。

## 3. Teams に投稿できるようにする

毎月だれかが立てるスレッド（例：「2026年 11月度／山田」）に、毎日の退勤時に `10/28 19:00 業務終了` のような返信を自分の名前で付けます。
**ワークフローは一人ひとつ、自分で作ります**（一度作れば、月が変わっても作り直しは不要です）。

### 3-1. ワークフローのひな形を作る（Teams）

1. Teams で、スレッドがあるチャネルの「…」→「**ワークフロー**」
2. 検索欄に `Send webhook alerts to a channel` と入れ、「**Webhook アラートをチャネルに送信する**」を選ぶ
   - 「特定のユーザーから〜」「組織内のユーザーから〜」は選ばないでください（サインインが必要で、このアプリからは送れません）
3. チームとチャネルを確かめて保存する
   - Teams の画面の「編集」は、チームとチャネルを選び直すだけの画面です。中身の入れ替えは次の Power Automate で行います

### 3-2. 「スレッドに返信する」に入れ替える（Power Automate）

1. ブラウザで <https://make.powerautomate.com> を開き、会社のアカウントでサインイン
2. 左の「**マイ フロー**」→ 3-1 で作ったフロー（「Webhook アラートを General に送信する」など）→ 上の「**編集**」
3. 縦に手順が並んだ画面になります。「**Teams Webhook 要求を受信したとき**」のすぐ下の「＋」→「アクションの追加」
4. 検索欄に「**Microsoft Teams**」と入れ、「詳しく見る」から「**チャネル内のメッセージで応答します**」（Reply with a message in a channel）を選ぶ
5. 次のように設定する

   | 項目 | 入れるもの |
   | --- | --- |
   | 投稿者 | **User**（自分の名前で返信され、自分で編集・削除できます） |
   | 投稿先 | 一覧から **チャネル**（「カスタム値として…」ではなく、一覧の項目を選ぶ） |
   | メッセージ ID | 欄を押す → 右に出る「**fx**」→ `triggerBody()?['messageId']` →「追加」 |
   | チーム | 一覧からスレッドがあるチーム |
   | チャネル | 一覧からスレッドがあるチャネル |
   | メッセージ | 欄を押す → 「**fx**」→ `triggerBody()?['html']` →「追加」 |

   - 式は**半角**で入れてください。日本語入力のままだと `‘ ’` のような記号になり「この式は無効です」と出ます。上の式をコピーして貼るのが確実です
   - 入れると、欄に色のついた札（`triggerBody()`）が入ります。札には中身が省略されて出るので、確かめたいときは上の「**コード ビュー**」を開き、`@triggerBody()?['messageId']` と `@{triggerBody()?['html']}` があれば正しく入っています
   - 「詳細パラメーター」の「ホスト型コンテンツ」はチェックしません
6. もとからある灰色の「**Attachments is null**」の手順を削除する（見出しをクリック →「⋮」→「削除」）
   - これを残したままだと保存できません（「Body を初期化する必要があります」というエラーが出ます）
7. 「Teams Webhook 要求を受信したとき」と「チャネル内のメッセージで応答します」の2つだけになったら、右上の「**保存**」
   - 保存前の赤いエラーの表示が残っていても、右の「×」で閉じて保存すれば大丈夫です

### 3-3. アプリに入れる

1. **ワークフローの URL**：Teams の「ワークフロー」→ 作ったワークフローを開き、「**Webhook リンクをコピー**」
   （Power Automate で「編集」→「Teams Webhook 要求を受信したとき」を開いたところにある URL でも同じです）
2. アプリの設定「**Teams のワークフロー URL**」に貼る
3. **スレッドのリンク**：Teams で今月のスレッドの最初の投稿（例：「2026年 11月度／山田」）にカーソルを置き、「…」→「**リンクをコピー**」
4. アプリの設定「**返信先スレッドのリンク（毎月）**」に貼る。下に「読み取れました」と出れば OK
5. 「**テストを1通送る**」を押し、スレッドに「浮世勤怠帖からのテストです」のような返信が付けば完成です。テストの返信は「…」→「削除」で消してください

> **ワークフローの URL は人に見せないでください。** URL を知っている人は、あなたの名前でそのスレッドに投稿できてしまいます。設定以外の場所に貼らないでください。

## 4. 毎日の使い方

### 出勤

1. ホームを開くと、あいさつ・今日の日付・現在時刻が出ます
2. 「今日の区分」を選びます
   - **通常**：出勤時刻は始業（10:00）で固定です
   - **遅刻**・**休日出勤**：出勤時刻を15分刻みで選べます
   - **有休**：「有休を登録する」から [登録](#5-遅刻早退欠勤有休のとき) に進みます
   - 土日祝は自動で「休日出勤」になります
3. 「**出勤する**」を押すと記録されます

### 退勤

1. ホームの「**退勤する**」を押します
2. 記録する退勤時刻を15分刻みで選びます（既定は終業 19:00）
3. 「Teams に投稿する文」を確かめます
   - 10:00 出勤・19:00 以降の退勤（残業も含む）：`11/20 19:00 業務終了`
   - 開始が 10:00 以外：`11/20 10:15 業務開始` ／ 理由 ／ `11/20 19:00 業務終了`（開始の理由の欄が出ます）
   - 19:00 より前に退勤：`11/20 15:00 業務終了` ／ 理由（早く終える理由の欄が出ます）
4. 「**Teams に投稿する**」を押すと、スレッドに返信されます
   - Teams に送りたくない日は「投稿せずに記録だけする」

押し忘れても、出勤 10:00・退勤 19:00 で記録されます。

### 暦で直す

タブ「暦」で日付をタップすると、その日の記録が下に出ます。
今日と過去の日は「**この日を直す**」で、勤怠区分・開始・終了・休憩・作業内容・備考を直せます。「記録なし」を選ぶと、その日は空欄になります。

## 5. 遅刻・早退・欠勤・有休のとき

1. タブ「**登録**」で、種類（遅刻・早退・欠勤・有休）を選ぶ
2. 日付・時刻（有休は 終日／午前休／午後休）・理由を入れて「**この内容で登録する**」
3. 「連絡のメール」の画面で、タブを切り替えて1通ずつ確かめて送ります
   - **自社宛て**：「自社に送る」
   - **現場先宛て**：「現場に送る」
   - **Teams**（欠勤・有休のときだけ）：「Teams に投稿」
4. 送るとメールアプリが、宛先・件名・本文が入った状態で開きます。**送信はメールアプリで押してください**
5. 送らないものは、押さなければ送られません。終わったら「登録を終える」

- 送る前に「**文面を直す**」で件名と本文を直せます。「元に戻す」で自動で作られた文に戻ります
- 「写す」で本文をコピーできます
- 自動で作られる文面の決まりは [docs/spec.md](docs/spec.md) にあります

## 6. 月初と月末にすること

### 月初：スレッドのリンクを貼り替える

月が変わると、ホームに「〇月の Teams のスレッドのリンクを、設定に貼ってください」と出ます。
新しいスレッドができたら、[3-3](#3-3-アプリに入れる) の 3〜4 と同じように、設定の「返信先スレッドのリンク」を貼り替えます。ワークフローの作り直しは不要です。

### 月末：Excel に貼る

1. タブ「まとめ」→「**月末の書き出しをする**」
2. 表を確かめます（土日祝と記録のない日は、月日だけで空欄）
3. どちらかで PC に渡します
   - **Excel用に写す**：コピーされた表を、PC へ送る（Teams の自分へのチャットなど）
   - **自分にメールで送る**：設定の「自分のメール」宛てにメールアプリが開きます
4. PC の会社の Excel で、その月の1日の「**月日**」のセルを選んで貼り付けます

列：`月日 / 勤怠区分 / 開始 / 終了 / 休憩 / 時間 / 作業内容（作業場所） / 備考`

## 7. 記録のバックアップ

記録はスマホの中にだけあるため、次のときに消えます。

- ホーム画面のアイコンを削除したとき
- ブラウザの「履歴と Web サイトのデータ」を消したとき
- 機種変更したとき

タブを閉じる・アプリを閉じる・スマホを再起動する、では消えません。

**取り方**：設定の「**記録を書き出す（ファイル）**」→ ファイルがスマホに保存されます。OneDrive や自分宛てのメールに置いておくと安心です。
**戻し方**：新しく入れたアプリの設定で「**記録を読み込む**」→ 保存したファイルを選びます。設定（氏名・宛先・URL など）も一緒に戻ります。

月末の書き出しのついでに、毎月取るのがおすすめです。

## 8. 困ったとき

| こんなとき | 見るところ |
| --- | --- |
| 記録が消えた | プライベートブラウズやアプリの中のブラウザで開いていないか。ホーム画面のアイコンから開いているか。バックアップがあれば「記録を読み込む」 |
| 「返信先スレッドのリンクが設定されていません」 | 設定に今月のスレッドのリンクを貼る |
| 「このリンクからは投稿を特定できません」 | スレッドの投稿の「…」→「リンクをコピー」で取ったリンクか確かめる |
| 「送信しました。届いたか確かめてください」 | 会社の環境で結果を確かめられない送り方になっています。スレッドに届いたか見てください |
| Teams に届かない | Power Automate のフローの「28 日間の実行履歴」を見る。実行が増えていて失敗していれば、その実行を開くと原因が赤く出ます。増えていなければ URL を確かめる |
| メールアプリが開かない | スマホに既定のメールアプリが設定されているか確かめる |
| 祝日の判定が違う | 祝日は計算で出しています。違う日は暦で直してください |

## このアプリについて

- 記録と設定はスマホの中にだけ保存され、作者を含めてほかの人には送られません。外に出るのは、自分で押したときの Teams への投稿と、メールアプリに渡す文面だけです。
- アプリは作者が直すと、使っている全員に反映されます（開き直したときに新しくなります）。
- デザインはデザインシステム「浮世勤怠帖」（和紙・墨・朱の三色、筆文字・明朝・ゴシックの三書体）に沿っています。挿絵は歌川国芳・河鍋暁斎ほか、パブリックドメインの作品から抜き出したものです。
- 仕様の詳細は [docs/spec.md](docs/spec.md)、ライセンスは [LICENSE](LICENSE)（MIT）を見てください。
